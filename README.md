# Мебель Сити

Сайт-каталог диванов магазина «Мебель Сити» (рынок Таатан-1, Бишкек, и филиал в Сокулуке).

- Каталог моделей с фильтрами, поиском и избранным
- Страница каждой модели с фото и характеристиками
- Заявки и вопросы о цене уходят в WhatsApp с готовым текстом

Статичный сайт: один `index.html` и папка `img/`, без сборки. Для публикации на Vercel достаточно импортировать репозиторий, настройки по умолчанию подходят.

Сделано в [SOZ](https://soz-ten.vercel.app).
